操作手册

绳上的每一个动作，都在这一页。

把绳放下来

  • 刘海停顿鼠标停在刘海左半区，剪贴板绳滑下来；停在右半区，出来的是便签绳。全屏应用上也能放。停顿时长三档可选：0.15 / 0.25 / 0.4 秒。没有刘海的屏幕，停在菜单栏上即可。
  • 快捷键⌃⌥C 放下 / 收起剪贴板绳，⌃⌥N 放下 / 收起便签绳。都可以在设置里录制成自己的，冲突即时提示。
  • 修饰键翻转按住修饰键，刘海左右两个区对调——一种手势管两条绳。
  • 收起绳子点绳子外面任意一处、再按一次快捷键，或指针离开片刻，绳就自己卷回去。

卡片上的手势

  • 悬停卡片微微浮起，左上角的 ✕ 和右上角的按钮淡入。
  • 单击复制到剪贴板，卡片下方闪一下「已复制」。便签例外：单击便签不复制，留给勾选框和滚动。
  • 双击粘贴回上一个使用的 app——自动切回去、替你按下 ⌘V。未授权「辅助功能」时退化为仅复制。便签双击是打开编辑。
  • 长按调系统「标注」编辑图片和 PDF，存盘后缩略图跟着更新。不能标注的卡片（文字、文件夹等）退化为复制。
  • 按住拖动拖进任何输入框、聊天窗口、邮件就是粘贴；拖进访达文件夹是真移动，原卡随之取下；拖到废纸篓上就是删除；哪儿都不接，卡片就飞回绳子。
  • 右键弹出菜单，见下。

卡片角落的按钮

  • 左上 ✕取下卡片：应用自己文件夹里的图片进废纸篓，外部文件只从绳上取下、原文件不动。盯住的卡也认这个 ✕，只是会先弹窗确认——删不删，再按一次才算数。
  • 右上放大镜打开预览窗：图片直接看，文字可滚动、可选中，PDF 等文档走系统快速查看，一次复制多个文件时列出清单。链接卡这里直接开浏览器，文件夹卡开访达。
  • 笔记的铅笔打开笔记编辑窗。
  • 笔记的勾选框点一下划掉一行；全部勾完，整张便签变淡但不会消失。

右键菜单

随卡片类型增减，常用的都在：

  • 复制文本卡在「复制纯文本」和「复制（带格式）」之间取反，跟设置里「复制时带上格式」开关正好互补：手势按开关来，右键永远备着另一副面孔。
  • 盯住 / 取消盯住盯住的卡豁免自动清理、豁免清空；✕ 还在，只是删之前会先问一声。
  • 打开 / 标注 / 在访达中显示标注只对图片和图片型 PDF 出现，走系统 Markup。
  • 在浏览器中打开链接文本卡才有。
  • 存储到桌面图片复制一份到桌面，文字存成 .txt。
  • 丢弃 / 移到废纸篓应用文件夹内的图丢弃，外部文件移到废纸篓。盯住的卡不给这一项：取下它走 ✕，那里会先确认。

键盘

  • ⌃⌥C放下 / 收起剪贴板绳（可在设置里录制）。
  • ⌃⌥N放下 / 收起便签绳（同上）。
  • ⌘↩（指针悬在卡片上）打开这张卡的预览，再按一次关闭。
  • Esc关预览、关搜索框；在笔记窗里按 Esc 保存并离开。
  • ⌘S保存笔记。

绳子本身

  • 翻页滚轮 / 触控板横向滑动翻页，胶囊两端的 ‹ › 逐屏翻，正中显示「当前 – 截止 / 总数」。
  • 胶囊工具条按类型筛选（全部 / 文字 / 链接 / 颜色 / 图片 / 文件）、搜索、只看盯住的卡、按日期回看以前挂过的卡。
  • 绳中间的 +新建便签。
  • 菜单栏图标实心 = 正在监控剪贴板，空心 = 已暂停。点图标弹菜单：呼出两条绳、新建便签、监控开关、系统截图自动上绳、设置、退出。

截屏也能直接上绳：打开菜单里的「系统截图自动上绳」，照常按 ⌘⇧3 或 ⌘⇧4，截图直接挂上绳子。详见主页特性介绍。
